GTA7: Pipeline Panic is an original two-player co-op platform game. Choose two of the three Richards, collect all three release keys, then get both runners to the exit while dodging Azure pipeline pipes and angry green birds (AGB). Each Richard always carries two laptops.

## How to play

- **Goal:** Collect all three golden release keys and bring both runners to the SHIP gate. Each runner has three retries; losing all retries on either runner ends the build.
- **Player 1:** `A` and `D` to move, `W` to jump. In the character picker, `Q` and `E` cycle through the Richards.
- **Player 2:** Left and Right arrows to move, Up arrow to jump. In the character picker, `,` and `.` cycle through the Richards.
- **Power-ups:** Pick up `VM` to move more slowly for a short time, `MB` (MacBook) to move faster, and `AI` to fly while holding the jump key.
- **Other controls:** `Enter` starts, resumes, or replays; `P` or `Esc` pauses; `R` restarts a run.
- **Time to play:** A short run takes about 3-6 minutes, depending on how often the AGB catches the team. The finish gate is the run's milestone.

## Setup

No installation or dependencies are required. Use a current desktop browser such as Chrome, Edge, or Firefox. Both players need a physical keyboard with the letter and arrow keys.

## Launch

Open `index.html` in a browser. The game runs locally in the page and does not need a server.

## Known issues

- The game uses visual-only feedback and has no sound.
- Keyboard ghosting on some laptop keyboards may prevent several simultaneous keys from registering. If that happens, try another keyboard or remap the browser's keyboard layout.
